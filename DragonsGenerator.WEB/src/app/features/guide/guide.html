Compte & connexion

  • Inscription — email, pseudo unique, mot de passe 8+ caractères, confirmation par mail.
  • Connexion — JWT ; vos personnages et campagnes sont synchronisés dans le cloud.
  • Mot de passe oublié — lien de réinitialisation valide 2 h.
  • Paramètres (/settings) — bio, couleur d’accent, emoji avatar, mot de passe, notifications push.
  • Profil public (/profile) — visible par vos amis.
  • Sans compte : brouillon local des personnages ; à la connexion, le perso en cours peut être sauvegardé.

Création de personnage

Assistant Forger un héros — 10 ou 11 étapes selon la classe (magie), niveaux 1 à 20.

  1. Espèce & sous-espèce
  2. Civilisation (carte d’Eana)
  3. Historique (prédéfini ou custom)
  4. Classe, sous-classe, styles, choix de progression (ASI, invocations sorcier…)
  5. Caractéristiques (point-buy)
  6. Compétences & maîtrises
  7. Équipement de départ
  8. Langues
  9. Magie (lanceurs) — sorts, grimoire, domaines…
  10. Identité — nom, alignement, backstory IA (Groq)
  11. Récap — PDF fiche + grimoire, sauvegarde cloud

Bibliothèque /characters : voir, éditer, dupliquer, exporter PDF.

Scénarios & campagnes

Assistant scénario

/story/create — 4 étapes : créatures, personnages (IA vie), aventure (IA 400–600 mots), récap PDF bestiaire + export campagne.

Campagnes multijoueur

/campaigns — hub MJ et joueur.

  • MJ — synopsis, créatures, rencontres, XP, sessions, héros pré-tirés, invitations amis, approbation des persos joueurs.
  • Joueur — proposer un personnage, voir documents publiés, activité, sessions à venir (sans spoilers MJ).
  • Onglets MJ : Résumé, Activité, Documents, Créatures, Pré-tirés, Rencontres, Joueurs.
  • Onglets joueur : Résumé, Activité, Documents, Pré-tirés, Joueurs.
  • Fil d’activité — invitations, XP, documents publiés, collecte d’initiative…
  • Sessions — planifier date/lieu ; rappels push 24 h et 1 h avant (si notifications activées).

Table de jeu (MJ)

Depuis une campagne : Démarrer la table ou route plein écran /campaigns/:id/play.

  • Notes en direct (sauvegarde auto)
  • Rencontres — +1/−1 kills, sync avec le tracker, distribution XP
  • Terminer la session → notes archivées, statut « jouée »

Initiative & combat

  • Combat autonome ou import depuis une rencontre / party approuvée
  • Ordre de tour, PV, conditions, mort (sync kills rencontre)
  • Collecter l’init — code + lien ; joueurs saisissent leur jet sur /campaigns/:id/init
  • Bandeau joueur + push quand la collecte s’ouvre
  • Flèches ↑↓ pour départager les égalités d’initiative
  • Fin combat — résumé dans les notes + entrée dans l’historique des combats (repliable)

Documents joueurs (handouts)

  • MJ : onglet Documents — créer, types (letter, carte, résumé…), markdown léger (**gras**, # titres, listes)
  • Publier → visible joueurs, push, activité cliquable
  • Joueur : aperçu depuis l’activité ou l’onglet Documents
