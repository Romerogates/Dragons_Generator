À quoi sert le backup ?

Tous les jours à 3 h, le serveur copie la base SQLite (comptes, campagnes, héros, tickets) et les fichiers uploadés dans ~/backups/dragons/, gardés 14 jours. Ce n’est pas un mail à ouvrir : c’est un filet si le VPS casse. Tu télécharges ici. Un mail ne part que si la copie a plus de 36 h de retard (alerte, une fois par jour max).
